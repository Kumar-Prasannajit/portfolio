Three threads this week.

## Brutal mode

A new look on the existing three-pane class names: primary and black colour tokens and a hard-cut toggle. I also recorded the height budget for rail 3 in the docs. The first swap spec was superseded by a re-skin spec.

## Stack and small fixes

- "Last used" for each Stack item is now derived from all recent GitHub activity.
- Stack tiles are read-only, and the Stack-to-Work filter is gone.
- IBM Plex Sans was dropped so the Turbopack build passes.
- Returning visitors' light or dark choice is kept, and the rail 3 stats are voiced.

## Drafting posts

I wrote a spec and a plan for automation that drafts the blog and weekly posts into pull requests. On the site side, GitHub reads now cover only allowed owners, with one token per owner. For the collector itself:

- It reads public repos only.
- One `GITHUB_TOKEN` is enough.
- The cloud proxy's placeholder token is named explicitly.
- It writes one short post per week and lists every source commit.

This post came out of that routine, and it goes live only after I merge the pull request.
