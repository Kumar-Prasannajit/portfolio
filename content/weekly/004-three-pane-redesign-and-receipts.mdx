It's been a while since the last entry. Four weeks, a lot of commits, two projects.
Grouped by project below, not by day.

## Portfolio

The big shape change: the site stopped being one scrolling page and became a three-pane
layout. A fixed identity panel on the left (portrait, live time, date, where the viewer
is watching from), the content in the middle, and a stats and theme rail on the right.
I wrote a spec for it first and then built it in nine numbered phases, which kept each
commit reviewable.

- **Theme tokens.** The first phase was a three-axis token architecture, so the layout
  work didn't have to touch colors.
- **Right rail.** Live stats, ambient ASCII, and a theme accordion with a character
  image per panel. The portrait gets tinted per character theme.
- **Stack.** The Stack section is now computed and ranks itself, and "last used" is
  derived from recent GitHub activity. I later made the tiles read-only and dropped the
  Stack-to-Work filter, which was more interaction than it was worth.
- **Work.** An in-flow Work section, `/work/[slug]` routes, and case-study pages with
  real screenshots.
- **Brutal mode.** A red-and-black re-skin on top of the three-pane class names, plus a
  hard-cut toggle between looks.
- **Smaller things.** A terminal-style boot preloader, scroll reveals and hero
  parallax on one motion system, a playable Snake on the contribution grid, and a
  recolored heatmap. I also added interaction sounds and then removed them the next day.
  {/* CHECK: is "removed them the next day" right? Sound added 2026-09-20, removed 2026-09-21 per commits. */}

The cursor needed two rounds. It now uses `mix-blend-mode: difference` on a square
cursor, and the blend sits on the outer wrapper so nav items invert instead of
vanishing. I dropped the grid-snap and idle-blink ideas after trying them.

### SEO and housekeeping

Per-page canonicals, generated Open Graph images for home, blog and weekly pages, RSS
feeds, sitemap dates, and Vercel analytics. A Lighthouse pass covered contrast, focus
and touch targets. I also fixed a theme hydration mismatch, and returning visitors now
keep their light/dark choice.

I also started on automation that drafts these posts from my GitHub activity into pull
requests, with the allowlist of repos it may read written down in code. This entry is
the first one it produced, so I'll be reviewing it with that in mind.

## Salonjaa

Most of the work was receipts. Customers can download a payment receipt, and the admin
side can too.

- First version used browser print, which is not a download. Switched to generating a
  real PDF.
- That broke on the logo (`next/image` doesn't survive html2canvas), then on modern
  color functions, so I swapped to `html2canvas-pro`.
- Then the layout: it now renders on a real A4 page with margins.

Around that: a password visibility toggle, a payment thank-you email, an invoice card,
viewable payment requests with soft-cancel, and admin client-form changes (editable
email, a server-generated password, a +91 phone field). Changing a client's email
resets their password. Deleting a client now works like deleting a repo on GitHub.

screenshots.
